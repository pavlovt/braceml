# @braceml/cli

Command-line compiler for [BraceML](https://github.com/pavlovt/braceml), a brace-based HTML template language.

```sh
npx @braceml/cli page.braceml                       # HTML to stdout
npx @braceml/cli page.braceml -t svelte -o out.svelte
npx @braceml/cli agents                             # add the BraceML reference to AGENTS.md
```

Installed in a project, the command is `braceml`.
